## Content SEO Checklist

### Every New Property Page Should Have:

- [ ] **Meta Tags**
  - [ ] Unique, descriptive title (50-60 characters)
  - [ ] Meta description (150-160 characters)
  - [ ] Target keywords (5-10 main keywords)
  - [ ] H1 tag with primary keyword
  - [ ] Multiple H2/H3 tags with related keywords

- [ ] **Images**
  - [ ] Alt text on all images
  - [ ] Descriptive file names
  - [ ] WebP format with fallbacks
  - [ ] Open Graph image (1200x630)
  - [ ] Compressed file sizes (<100KB)

- [ ] **Structured Data**
  - [ ] Property schema (RealEstateListing)
  - [ ] Pricing schema
  - [ ] FAQ schema
  - [ ] Agent information
  - [ ] Address schema

- [ ] **Internal Linking**
  - [ ] Link to related properties (3-5 links)
  - [ ] Link to location pages
  - [ ] Link to services page
  - [ ] Breadcrumb navigation
  - [ ] Link text with keywords (not "click here")

- [ ] **User Experience**
  - [ ] Mobile responsive
  - [ ] Load time <3 seconds
  - [ ] Clear call-to-action (CTA)
  - [ ] Contact information visible
  - [ ] WhatsApp button present

## Technical SEO Checklist

### Core Web Vitals
- [ ] LCP (Largest Contentful Paint) < 2.5s
- [ ] FID (First Input Delay) < 100ms
- [ ] CLS (Cumulative Layout Shift) < 0.1

### Mobile
- [ ] Mobile-responsive design
- [ ] Touch-friendly buttons
- [ ] Readable font size (16px minimum)
- [ ] No horizontal scrolling

### Performance
- [ ] CSS minified and compressed
- [ ] JavaScript minified
- [ ] Images optimized
- [ ] Lazy loading implemented
- [ ] Browser caching enabled

### Crawlability
- [ ] robots.txt allows crawling
- [ ] No noindex on public pages
- [ ] No nofollow on internal links
- [ ] Sitemap updated weekly
- [ ] No 404 errors

### SSL/Security
- [ ] HTTPS enabled
- [ ] SSL certificate valid
- [ ] No mixed content (HTTP/HTTPS)

## SEO Best Practices

### DO ✅
- ✅ Create unique content for each page
- ✅ Use descriptive, keyword-rich titles
- ✅ Write compelling meta descriptions
- ✅ Include proper heading hierarchy (H1, H2, H3)
- ✅ Use natural keyword distribution
- ✅ Add internal links to related pages
- ✅ Optimize images with alt text
- ✅ Make content mobile-friendly
- ✅ Load pages fast
- ✅ Use structured data/schema
- ✅ Include calls-to-action
- ✅ Monitor and improve regularly

### DON'T ❌
- ❌ Keyword stuffing
- ❌ Duplicate content
- ❌ Cloaking or hidden text
- ❌ Private link networks
- ❌ Unnatural link schemes
- ❌ Auto-generated content
- ❌ Misleading titles
- ❌ Gateway pages
- ❌ Mixing schemas incorrectly
- ❌ Using noindex on important pages
- ❌ Blocking crawlers in robots.txt unnecessarily
- ❌ Ignoring mobile users

## Link Velocity Guidelines

### New Properties
- Week 1: 2-3 citations/mentions
- Week 2-3: 1-2 directory listings
- Month 1: 3-5 total backlinks

### Mature Properties
- Maintain 1-2 backlinks monthly
- Build 5-10 citations in first month
- Gradual, consistent growth

### Avoid
- ❌ Sudden spike in links (looks unnatural)
- ❌ All links from same domain
- ❌ All links with exact match anchor text
- ❌ Links from unrelated sites
